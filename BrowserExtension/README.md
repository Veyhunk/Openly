# Openly 浏览器扩展

1. 打开 Chrome 或 Edge 的扩展管理页，启用开发者模式，选择“加载已解压的扩展程序”，选中此目录。
2. 复制扩展 ID，在 Openly → 打开接管 → 应用打开能力中选择浏览器，填入 ID，点击“连接扩展”。
3. 在需要使用的每个个人资料中安装。需要选择无痕窗口时，在扩展详情中允许无痕访问。

在 Openly 选择浏览器个人资料后，点击“读取浏览器窗口与分组”。短暂出现的连接页会在完成后关闭。扩展仅在连接页打开时运行，使用本机 Native Messaging 读取一次性请求；没有后台常驻连接。

移动 Openly.app 后请重新点击“连接扩展”，以更新本机程序路径。
