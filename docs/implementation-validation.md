## 启动测量

Release 构建；应用缓存已建立；每次接收器进程均重新启动。记录从发送系统打开请求到 SwiftUI 选择器首次 `onAppear` 的时间，包含调度和启动；这是首屏出现指标。每组 10 个样本。

| 请求 | 中位数 | 首个样本 | 其余样本范围 |
|---|---:|---:|---:|
| 本地文件 | 197.32 ms | 778.48 ms | 173.96–218.26 ms |
| 网页链接（首版列表） | 312.04 ms | 804.03 ms | 277.01–388.48 ms |
| 本地文件（新版图标网格，独立测试接收器） | 217.36 ms | 324.68 ms | 195.55–262.68 ms |

这组结果尚未满足“所有冷启动 P95 ≤ 300 ms”的建议目标。首个样本包含首次运行成本，网页组使用了兼容旧格式的能力缓存；更新缓存后的复测因已有接收器正在使用而停止，保留当前请求。后台能耗尚未用 Instruments 长时间采样。

复测命令：编译 `scripts/benchmark.swift`，运行生成程序；添加 `--web` 测量网页事件。可用 `OPENLY_BENCH_APP` 指定 `prepare-ui-test.py` 创建的独立接收器，避免中断真实请求。已有接收器打开时测量程序会退出，避免打断当前请求。

## 批量确认调查

批量接管使用临时的轻量 Receiver 注册副本：副本只声明本次所选 UTI，并以 `LSHandlerRank=Owner` 注册。低于 macOS 26.4 时可按注册结果批量核验；macOS 26.4 及以上会由系统对每个默认应用变更要求确认，公开 API 没有合并这些确认的接口，界面会明确提示逐项确认。副本保留在 Openly 的应用支持目录中供已接管类型继续唤起。

浏览器 Profile 读取同时展示 `Local State` 中的 `user_name`（无邮箱时回退到 `gaia_name`）。Chrome/Edge 已运行时，普通 Profile、扩展桥接和新窗口启动统一通过 `open -n --args --profile-directory=...`，避免 Chromium 单例进程吞掉 Profile 参数。

轻量生命周期已在发布包中验证：`Cmd+W` 与红色关闭按钮都进入同一窗口关闭路径，常驻后台进程继续运行；再次启动 Openly 会重建管理窗口并保留当前页面；窗口关闭后 Dock 窗口项消失，菜单栏入口由后台状态接管。管理窗口位置写入本地偏好并在重建时恢复。偏好设置提供立即、10 秒、30 秒和 1 分钟的轻量模式延迟。

管理界面已将接管提交收敛为一次批量确认入口；确认后按 UTType 顺序写入并逐项核验，失败项进入结果页，可单独重试。系统是否额外显示 Launch Services 确认由 macOS 当前策略决定。
